# Pahadi Stay Booking Platform

A web application for connecting travelers with local homestays in Uttarakhand.

Tech Stack:
- React JS
- Node.js
- Express.js
- MongoDB

Features:
- Homestay Listings
- Booking Requests
- Tourist Attraction Guide
- AI Travel Assistant
